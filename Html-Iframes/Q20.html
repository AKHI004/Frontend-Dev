HTML Head Elements Demo Page

This page demonstrates all the important elements that belong in the <head> section of an HTML document.

Elements Included:

  • <title> - Defines the page title shown in browser tabs
  • <meta charset> - Sets character encoding
  • <meta description> - Provides page description for SEO
  • <meta author> - Specifies the document author
  • <base> - Sets the base URL for relative links
  • <link> - Links to external resources like stylesheets and favicons
  • <style> - Contains internal CSS styles
  • <script> - Contains or references JavaScript code
